# 小G桌宠 · Windows 10/11

一只住在桌面上的小机器人，可以散步、眨眼、挥手、安静陪伴，也可以帮你记待办、专注计时、写笔记和记住重要日子。

## 下载安装

打开 [最新版本下载页](https://github.com/Shaky-00/gteacher-desktop-pet/releases/latest)，下载 **GTeacher-Setup-v1.1.0.exe**，双击安装。安装包提供开始菜单入口和可选桌面快捷方式。

升级前退出旧版，再运行新版安装包，原来的称呼、设置、待办和笔记会保留。程序不会静默安装更新。

## v1.1.0

- 显示名称统一为“小G”，使用保留大眼睛、只留头部的新图标。
- 右键常用功能统一为 ChatGPT 网页、天气、工作台；待办、番茄钟、笔记和重要日子都在工作台中。
- 重要日子改为年月日分别选择，自动处理大小月与闰年；名称框提供“写下重要的日子”占位提示。
- 基本设置与语料库采用圆角输入框、胶囊页签；称呼使用系统原生输入控件，改善焦点和文字显示。
- 桌宠大小分十档，可拖动实时预览，保存后生效，取消恢复。
- 打开 ChatGPT 的快捷键固定为 **Ctrl+Alt+G**。
- 可选的 Windows 本地语音：默认关闭，提供系统音色选择、音量、试听与停止，不需要 API 或联网语音服务。音色取决于本机已有的桌面语音。
- 更新检查区分暂无正式版、没有新更新、网络错误、超时与响应异常。

## 日常使用

右键小G打开菜单。活动模式会走动，陪伴模式留在原地。点击小G会互动，拖动可以移动位置。

**控制台 → 语音试听**：先试听音色；喜欢后勾选语音开关并保存。不喜欢可以随时关闭。没找到音色或音频设备时会给出提示，仍可使用其他功能。

**工作台**：添加和勾选待办；开启 25/45 分钟专注或 5 分钟休息；记录标题与笔记；保存每年重复或一次性的纪念日。番茄钟和关怀只在程序运行时生效，退出后不继续计时。

天气需要联网，使用手动填写的城市查询 Open-Meteo；不读取 GPS。检查更新请求 GitHub 的公开 Release 信息，不上传笔记或称呼。小G不会读取屏幕或 ChatGPT 聊天内容。

## 从源码启动

完整下载并解压源码，双击 **start.bat**。需要 Windows 10/11 自带的 **Windows PowerShell 5.1 + WPF**，不需要 Python、Node.js 或聊天 API。请保留根目录中的四个运行脚本、sprites 和 assets 目录。遇到错误可用 debug.bat 查看。

程序不默认开机自启。源码启动与安装版使用同一个个人数据目录，启动前请退出另一个版本。

## 数据与升级

本地数据在 `%LOCALAPPDATA%\GTeacherDesktopPet`：

- settings.json：称呼、语料库、大小、模式、置顶和可选语音设置。
- life.json：待办、笔记、天气城市、关怀、重要日子与专注记录。
- life.json.bak：上一次成功保存的手账备份。
- update-check.log：最近一次更新查询诊断。

安装与卸载不会清空个人数据。暂无跨设备同步，换电脑前可备份该目录。

## 维护与构建

Windows 构建流程会检查 PowerShell 语法、加载 WPF 界面并验证称呼输入框和默认关闭的语音逻辑，然后使用 PS2EXE 1.0.18、Inno Setup 6 生成安装包。

推送 main 只构建并保存测试产物；推送与 version.txt 一致的版本标签（例如 v1.1.0），或手动运行工作流并选择发布，才创建 GitHub Release。已发布的版本不覆盖安装包，后续更新递增版本号。

版本需同步维护 version.txt、UpdateDesk.ps1 和 installer/GTeacher.iss。脚本启动、安装版与构建产物的内部路径保持兼容，仓库名不变。

目前安装包没有代码签名证书，Windows 可能显示未知发布者。请从本仓库下载并核对 SHA-256。PS2EXE 是脚本封装，不是源码加密。系统实际键盘/中文输入法、不同 DPI 和音色效果仍以本机使用为准。

源代码和角色素材公开；正式开源许可证仍待维护者选定。
