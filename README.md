# 小 G 老师桌宠 v1.0.0 · Windows 分享版

一只住在 Windows 10/11 桌面的原创小机器人：它可以散步、眨眼、挥手、陪伴，还能陪你记待办、专注、收集灵感与记住重要日子。

沿用 **Windows PowerShell 5.1 + WPF**，不需要安装 Python、Node.js 或 ChatGPT API，也不要求注册账号。查询天气时需要联网，其他功能可在本地运行。

## 给家人、朋友和同事：下载安装

1. 打开 [GitHub Releases 下载页](https://github.com/Shaky-00/gteacher-desktop-pet/releases/latest)。
2. 下载 `GTeacher-Setup-v1.0.0.exe`（不是源码 ZIP），双击安装。
3. 安装时可以选择创建桌面快捷方式；安装后也能在开始菜单找到「小 G 老师」。
4. 第一次运行可以设置自己的称呼。右键小 G 可打开天气、待办、番茄钟和生活手账。
5. 日后升级：退出旧版小 G，下载并运行新版 Setup.exe，即可保留原来的个人数据。

**Windows 安全提示**：目前安装包尚未购买代码签名证书，Windows SmartScreen 可能提示未知发布者。请只从上面的官方仓库发布页下载，核对发布页提供的 SHA-256 校验值，并遵守公司电脑的安全管理规则；不要为了安装而关闭安全防护。

**还没有看到 Setup.exe？** 项目维护者需要先让 GitHub Actions 的 Windows 构建成功，并手动发布 v1.0.0。仓库里的源码 ZIP 并不是安装程序。

## 从公开源码启动（开发者）

在 Windows 10/11 上克隆仓库或下载源码 ZIP，保持 `GTeacherPet.ps1`、`LifeDesk.ps1`、`UpdateDesk.ps1` 和 `sprites` 目录同级，双击 `start.bat`。本方式仍然需要系统自带的 Windows PowerShell 5.1 + WPF。不需要 Python、Node.js 或 ChatGPT API。

如果运行出现问题，双击 `debug.bat` 查看错误并反馈。程序默认不会开机自启。

## v1.0.0 新变化

- **单文件安装包**：由 GitHub Actions 的 Windows 环境使用 PS2EXE 和 Inno Setup 构建带卸载功能的安装程序，用户不再需要每次解压整份源码。
- **版本检查**：右键「检查小 G 更新」可手动查询 GitHub 最新稳定版；启动时最多每 24 小时自动查询一次。只有用户确认后才打开下载页，**不会静默下载或安装**。
- **专注不打扰**：自动更新提示会等到正在进行的番茄钟结束后再出现。
- **升级不丢手账**：沿用 `%LOCALAPPDATA%\GTeacherDesktopPet` 中的设置与笔记；不随安装包覆盖。

## 继承 v0.9 的可爱功能

- **圆润手账**：生活手账采用暖黄色、圆角标签页、柔和输入框和按钮；关怀间隔可以直接点选圆角小胶囊。
- **天气观察站**：右键「看看今日天气」，小 G 先摆出思考姿势，随后打开独立天气小卡片。卡片内可修改城市、重新查询；天气不再占用生活手账标签页。
- **脚边专注钟**：开始 25/45 分钟番茄钟或 5 分钟休息后，小 G 下方出现小闹钟，逐秒显示剩余时间；拖动小 G 时会跟随。暂停显示暂停状态，重置或完成时消失。靠近屏幕底部时，小 G 会尽量往上挪一些给闹钟让位。
- **定时提醒暂时下线**：新版不再显示定时提醒界面、也不再触发旧提醒。v0.8 的提醒记录仍保存在本地 `life.json`，以后重新开放时可继续使用。

## 当前可用的生活功能

| 功能 | 入口与使用方式 |
| --- | --- |
| ☀ 今日天气 | 右键「看看今日天气」→ 思考动作 → 独立天气卡片。默认沿用上次填写的城市，可修改并重新查询。 |
| 📝 今日 To-do | 右键「今日 To-do」或手账中的「今日待办」：添加、完成/撤销、删除任务。 |
| 🍅 番茄钟 | 右键一键开始/暂停/继续；或在手账「专注时光」选择 25 分钟、45 分钟、5 分钟休息，及重置。 |
| 📒 小 G 记事本 | 在手账中添加标题、正文并保存；选中已有笔记可编辑，修改后记得再次点击保存。 |
| 🌷 日常关怀 | 在「关怀设置」中切换开关，选择 30/45/60/90/120 分钟间隔并保存。专注计时中尽量不打扰。 |
| 🎂 重要日子 | 填写名称、日期以及是否每年重复，保存生日、纪念日和截止日倒计时。 |

天气使用 Open-Meteo 免费非商业接口；需要网络，但不会读取 GPS 或自动获取设备位置。只使用自己输入的城市查询。天气接口有可用性和使用条款限制。

### 数据保存在哪里？

```text
%LOCALAPPDATA%\GTeacherDesktopPet\settings.json   ← 称呼、语料库、动画模式、置顶、快捷键等
%LOCALAPPDATA%\GTeacherDesktopPet\life.json       ← 待办、笔记、天气城市、关怀、纪念日、专注记录、旧提醒
%LOCALAPPDATA%\GTeacherDesktopPet\life.json.bak   ← 生活手账上一次成功保存的备份
```

升级不会清空数据，卸载时默认也不会删除这些个人文件。不同 Windows 账户分别保存本地信息，暂无跨设备自动同步；换电脑前可以备份以上 JSON 文件。天气联网请求不会上传待办、笔记、称呼或其他私人记录。

自动更新检查仅请求 GitHub 公开的最新 Release 元信息，另在同一目录记录 `last-update-check.txt`（上次检查时间）。不上传待办、笔记或昵称。

## 桌宠互动仍然保留

- **活动模式**：自动探索、走路、转身、观察、打盹与挥手，台词更俏皮。
- **陪伴模式**：不主动到处走，动作频率更慢，台词偏陪伴和鼓励。
- 悬停挥手、点击回应、拖动位置、眨眼、动态睡眠气泡与思考小星星继续保留。
- 右键使用淡黄色圆角菜单，提供常用功能；「小 G 控制台」可修改昵称、快捷键、置顶和语料库。
- 默认 `Ctrl+Alt+G` 打开 ChatGPT 网页，可在控制台更换字母。小 G 不会自动读取你的 ChatGPT 聊天内容。

## 运行说明

- 番茄钟与日常关怀只在小 G **运行时**生效。关闭程序会结束正在计时的番茄钟；再次启动不会恢复未完成的计时。
- 天气数据是网络天气服务提供的参考信息，可能有误差。
- `start.bat` 使用的 `-ExecutionPolicy Bypass` 仅适用于启动的 PowerShell 进程，不修改系统级执行策略；如设备管理员禁止 PowerShell，请遵守相关规定。
- **开发环境不是 Windows，尚未完成真实 Windows 10/11 的 WPF 图形运行验收**。GitHub Actions 负责验证打包是否成功；安装后还需要在真实 Windows 设备验收天气小窗、关怀开关、专注倒计时、更新提示和卸载。

## 维护者：构建与发布

1. 每次升级要同步修改 `version.txt`、`UpdateDesk.ps1` 的 `$script:PetVersion`、`installer/GTeacher.iss` 的默认版本和 `README.md` 版本说明。
2. 推送到 `main` 会自动触发 Windows 打包。到 GitHub 仓库 **Actions → Build Windows installer** 查看构建结果，在构建记录的 Artifacts 下载测试安装包。
3. 确认安装、运行、升级和数据保留均正常后，点 **Run workflow**，将 `publish_release` 设为 `true`，才会创建公开的 GitHub Release（并附 `.sha256` 校验文件）。
4. 如果要通过 Git tag `v1.0.0` 触发发布，也必须保证它与 `version.txt` 一致。**不要对已经发布的同一个版本覆盖安装包**；下一次发布应提升版本号。

所需 Windows 打包工具由工作流自动安装：PS2EXE 1.0.18、Inno Setup 6。不在仓库中保存任何 API 密钥、密码或用户手账。`assets/gteacher.ico` 是由项目中的原创头像转换得到。

PS2EXE 将 PowerShell 脚本封装进 Windows 可执行文件，**不代表源码被加密、不可提取或已获得代码签名**。项目目前公开源文件与运行所需的角色素材；正式的源码授权许可证尚待维护者选择。
